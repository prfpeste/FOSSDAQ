# Documentation

This directory contains the documentation files for the `ai-4x-4to20mA` module.

## Files

### [build-manual.pdf](build-manual.pdf)

Build and assembly manual for the `ai-4x-4to20mA` measurement module.

The document contains the information required to assemble the module, including the electrical connections, components, wiring, current measurement circuitry, and mechanical assembly.

### [connector_labels.pdf](connector_labels.pdf)

Printable connector labels for the `ai-4x-4to20mA` enclosure.

The labels are intended to be printed at 100% scale, cut out, and attached to the enclosure to identify the connectors and channels.

## Notes

- PDF files are provided as the final documentation format.
- When printing `connector_labels.pdf`, use **100% / actual size** to preserve the intended dimensions.
