# CAD Files

This directory contains the FreeCAD source files for the enclosure of the `ai-4x-4to20mA` module.

## Files

### [enclosure_body.FCStd](enclosure_body.FCStd)

FreeCAD source file for the main enclosure body.

### [enclosure_body+slate.FCStd](enclosure_body+slate.FCStd)

FreeCAD source file containing the enclosure body together with the slate.

### [enclosure_lid.FCStd](enclosure_lid.FCStd)

FreeCAD source file for the enclosure lid.

### [enclosure_pin.FCStd](enclosure_pin.FCStd)

FreeCAD source file for the enclosure pin.

### [slate.FCStd](slate.FCStd)

FreeCAD source file for the slate.

## Notes

- The `.FCStd` files are the editable CAD source files.
- FreeCAD is required to modify the models.
- Ready-to-print files are available in the [`../print`](../print) directory.
