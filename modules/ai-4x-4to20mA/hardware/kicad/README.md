# KiCad Files

This directory contains the electrical schematic and KiCad project files for the `ai-4x-4to20mA` module.

## Files

### [ai-4x-4to20mA-schematic.pdf](ai-4x-4to20mA-schematic.pdf)

PDF export of the electrical schematic for quick viewing without KiCad.

### [ai-4x-4to20mA.kicad_pro](ai-4x-4to20mA.kicad_pro)

KiCad project file containing the project settings and configuration.

### [ai-4x-4to20mA.kicad_sch](ai-4x-4to20mA.kicad_sch)

Editable KiCad schematic source file.

## Notes

- KiCad is required to edit the project and schematic files.
- The PDF schematic is provided for convenient viewing and documentation.
- The `.kicad_pro` and `.kicad_sch` files should be kept together in the same directory.
