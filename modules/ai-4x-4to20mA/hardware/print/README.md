# 3D Printing Files

This directory contains the 3D-printable enclosure files for the `ai-4x-4to20mA` module.

Both `.3mf` and `.stl` files are provided where applicable.

## Files

### [enclosure_body+slate.3mf](enclosure_body+slate.3mf)

3MF file containing the enclosure body together with the slate.

### [enclosure_body+slate.stl](enclosure_body+slate.stl)

STL file containing the enclosure body together with the slate.

### [enclosure_complete.3mf](enclosure_complete.3mf)

Complete 3MF project containing all enclosure parts.

This is the recommended and easiest file to use for 3D printing, as all required enclosure components are already included in a single project.

### [enclosure_lid.3mf](enclosure_lid.3mf)

3MF file for the enclosure lid.

### [enclosure_lid.stl](enclosure_lid.stl)

STL file for the enclosure lid.

### [enclosure_pin.3mf](enclosure_pin.3mf)

3MF file for the enclosure pin.

### [enclosure_pin.stl](enclosure_pin.stl)

STL file for the enclosure pin.

## Notes

- `.3mf` files are recommended when using compatible slicer software because they can preserve additional project and print information.
- `.stl` files are provided for compatibility with other slicers.
- Editable CAD source files are available in the [`../cad`](../cad) directory.
