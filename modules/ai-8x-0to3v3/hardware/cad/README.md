# Ready-to-print files

Download and print - no CAD software needed.

- `*.3mf` - open directly in your slicer (Bambu Studio, OrcaSlicer, PrusaSlicer, Cura)
- `*.stl` - universal mesh format, converted from the 3MF files
- `*.FCStd` - FreeCAD

Print settings: PLA (matte), 0.4 mm nozzle, no supports required.
See `../../docs/build-manual.pdf` for the full printing guide.
