# Documentation

This directory contains the documentation files for the `di-4x-5V` module.

## Files

### [build-manual.pdf](build-manual.pdf)

Build and assembly manual for the `di-4x-5V` measurement module.

The document contains the information required to assemble the module, including the electrical connections, components, wiring, and mechanical assembly.

### [connector_labels.pdf](connector_labels.pdf)

Printable connector labels for the `di-4x-5V` enclosure.

The labels are intended to be printed at 100% scale, cut out, and attached to the enclosure to identify the connectors and channels.

## Notes

- PDF files are provided as the final documentation format.
- When printing `connector_labels.pdf`, use **100% / actual size** to preserve the intended dimensions.
