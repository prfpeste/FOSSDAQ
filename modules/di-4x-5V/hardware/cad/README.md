# Enclosure CAD Files

## Files

- `enclosure_body.FCStd`  
  Main body of the enclosure.

- `enclosure_lid.FCStd`  
  Lid of the enclosure.

- `enclosure_pin.FCStd`  
  Pin used as part of the enclosure.

- `slate.FCStd`  
  External rail-mounting part attached to the outside of the enclosure.

- `enclosure_body+slate.FCStd`  
  Assembly consisting of the enclosure body and the slate.  
  This file shows the correct position of the slate on the outside of the enclosure.

## Software

The CAD files were created with **FreeCAD** and can be opened and modified using FreeCAD.

## Usage

The individual files can be used to modify the corresponding enclosure parts.

The `enclosure_body+slate.FCStd` assembly can be used to check the position and fit of the slate on the enclosure.

For 3D printing, use the separately provided print files.
