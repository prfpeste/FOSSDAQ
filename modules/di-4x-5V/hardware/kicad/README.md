# KiCad Files

This folder contains the KiCad project files and the circuit schematic for the `di-4x-5V` measurement module.

## Files

- `di-4x-5V.kicad_pro`  
  KiCad project file. Open this file to load the complete KiCad project.

- `di-4x-5V.kicad_sch`  
  KiCad schematic file containing the electrical circuit of the measurement module.

- `di-4x-5V-schematic.pdf`  
  PDF export of the schematic for quick viewing without KiCad.

## Software

The project files were created with **KiCad**.

KiCad can be downloaded from:

https://www.kicad.org/

## Usage

To edit the schematic, open:

`di-4x-5V.kicad_pro`

The schematic can then be viewed and modified in the KiCad Schematic Editor.

If KiCad is not installed, the circuit can also be viewed directly using:

`di-4x-5V-schematic.pdf`
