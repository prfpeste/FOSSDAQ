# Enclosure Print Files

This folder contains the ready-to-print files for the enclosure of the measurement module.

## File Formats

The parts are provided in two different file formats:

- `.stl` – Universal 3D model format that can be imported into almost any slicer.
- `.3mf` – Ready-to-use print file for slicers such as Bambu Studio, PrusaSlicer, and compatible software.

## Files

- `enclosure_body+slate.stl`  
  Enclosure body with the slate.

- `enclosure_body+slate.3mf`  
  Ready-to-print version of the enclosure body with the slate.

- `enclosure_lid.stl`  
  Lid of the enclosure.

- `enclosure_lid.3mf`  
  Ready-to-print version of the enclosure lid.

- `enclosure_pin.stl`  
  Pin used for the enclosure.

- `enclosure_pin.3mf`  
  Ready-to-print version of the enclosure pin.

- `enclosure_complete.3mf`  
  Contains all parts required for one complete enclosure arranged together on a single print bed:
  - enclosure body with slate
  - enclosure lid
  - enclosure pin

## Printing

For a complete enclosure, the easiest option is to use:

`enclosure_complete.3mf`

This file already contains all required enclosure parts on one print bed.

Alternatively, the individual `.3mf` files can be used if only a specific part needs to be printed.

The `.stl` files are provided as universal models and can be imported into other slicers or used with custom print settings.
