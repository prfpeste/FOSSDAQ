# lan-dashboard/

Small Flask web app for the Raspberry Pi: a full-screen page of buttons that
link to other local services (by default a "NodeRed" button pointing at
`http://nodered.hotspot`). It's what the hotspot's captive portal opens onto
(see `../setup-hotspot.sh`). A password-protected admin mode lets you add,
edit, delete, reorder, and hide/show buttons, change the page title/logo/
color theme, change the admin password, and change the hotspot Wi-Fi
name/password — all from the browser, without SSH.

## Files

| File | Purpose | What you can edit |
|---|---|---|
| `app.py` | The Flask application: routes for the public page, the buttons API (CRUD), settings (title/theme/logo), admin login/password change, hotspot config, and shutdown/restart. Reads/writes the JSON data files below. | `GIT_REPO_URL` (footer link) and `DEFAULT_SETTINGS`/`DEFAULT_HOTSPOT_CONFIG` near the top if you want different out-of-the-box defaults. Add routes here if you need new admin functionality. Day-to-day content changes (buttons, title, password) should go through the web UI, not this file. |
| `templates/index.html` | The single HTML page (public view + admin view) rendered by Flask/Jinja. | Edit for layout/markup changes to the dashboard page. |
| `static/style.css` | All styling, including light/dark theme. | Edit for visual/theme changes. |
| `static/script.js` | Client-side logic: admin login, button CRUD via the API, drag-reorder, logo upload, theme toggle, hotspot settings form. | Edit for front-end behavior changes. |
| `static/uploads/` | Stores the uploaded logo image (via admin mode). `.gitkeep` just keeps the empty folder in version control. | Don't edit by hand — managed by the app (upload/remove logo in admin mode). |
| **`buttons.json`** | **The dashboard's buttons/links** — each entry has `id`, `label`, `url`, `visible`, `order`. | Normally edited via the admin UI ("New button" tile, pencil/eye/✕ icons). Can also be hand-edited (valid JSON) and picked up on next request — useful for scripted/bulk setup, e.g. adding a link to a newly wired-up service. |
| `settings.json` | Page header text (`eyebrow`, `title`), color `theme` (`light`/`dark`), and `logo_filename`. | Normally edited via admin mode (click the headings to edit inline, use the moon/sun icon for theme, upload icon for logo). |
| `admin_config.json` | *(created automatically)* Hashed admin password, once it's been changed via the web UI. Takes precedence over `ADMIN_PASSWORD` in `.env`. | Don't hand-edit — change the password via the 🔑 icon in admin mode instead. |
| `hotspot_config.json` | Hotspot SSID/password, read by `../setup-hotspot.sh` at hotspot start and overridable from the dashboard's Wi-Fi settings admin panel. | Edit via the admin UI, or by hand if you need to preset values before first boot. |
| `.env` | *(not shipped, created during install/first run)* `SECRET_KEY` (Flask session signing) and optionally `ADMIN_PASSWORD`. | Set `ADMIN_PASSWORD` here for the initial admin password (default is `admin` if unset); `SECRET_KEY` is auto-generated by `../install.sh`. |
| `requirements.txt` | Python dependencies: `Flask`, `gunicorn`. | Add packages here if `app.py` gains new dependencies. |
| `lan-dashboard.service` | systemd unit template (installed as `/etc/systemd/system/lan-dashboard.service`, with paths/user substituted by `../install.sh` for the actual `DASHBOARD_USER`/directory). Runs the app via `gunicorn`. | Edit `ExecStart` if you want different gunicorn options (e.g. worker count `-w`, bind port). The as-shipped `User=pi` / `/home/pi/...` paths are placeholders that `install.sh` rewrites automatically — don't rely on editing this file for a different user, use `DASHBOARD_USER=... sudo -E ./install.sh` instead. |

## Data & backup

Buttons live in `buttons.json`. Once the admin password is changed via the
web UI, `admin_config.json` is created (hashed password only, no plaintext)
and takes precedence over `ADMIN_PASSWORD` in `.env`. Headers, color theme,
and the uploaded logo are stored in `settings.json` and `static/uploads/`,
and persist across Pi reboots. To back up, save `buttons.json`,
`settings.json`, `static/uploads/`, and (if present) `admin_config.json`.

## Using admin mode

- Click the "Admin" button top-right and enter the password. The default is ´Password`.
- In admin mode, every tile shows three icons: eye (show/hide), pencil
  (edit), ✕ (delete) — plus a "New button" tile at the end.
- Hidden buttons are invisible to normal visitors and shown (semi-transparent)
  only in admin mode.
- The two headings ("LOCAL NETWORK" and the title) are click-to-edit in admin
  mode; changes save on blur/Enter.
- A logo (PNG/JPG/GIF/WEBP/SVG, max 3 MB) can be uploaded via the image icon
  next to the headings, visible to all visitors; remove it via the ✕ icon.
- A moon/sun icon top-right toggles dark/light mode for all visitors, and
  persists across restarts.
- A key icon (🔑) next to the Admin button lets you change the admin password
  (current password + new password, min. 4 characters, entered twice).
- The network icon (📶) lets you change the Name (SSID) and password of the hotspot.
  Changes only take affect after the RaspberryPI has been restarted.
